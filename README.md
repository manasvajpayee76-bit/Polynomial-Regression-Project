# Polynomial Regression on Student Exam Scores

This project implements a machine learning model that uses polynomial regression to predict students' exam scores based on study hours. It calculates the Mean Squared Error (MSE) to check model accuracy and plots the regression curve.

## Features
- Load dataset (`pandas`)
- Generate polynomial features (`sklearn.preprocessing.PolynomialFeatures`)
- Train model (`sklearn.linear_model.LinearRegression`)
- Make predictions and calculate MSE
- Plot regression curve using Matplotlib

## Requirements
To run this code, you need the following libraries:
- pandas
- numpy
- scikit-learn
- matplotlib

You can install them using pip:
```bash
pip install pandas numpy scikit-learn matplotlib
